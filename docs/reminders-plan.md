# План реализации напоминаний

Спецификация: [reminders-design.md](reminders-design.md). Последовательная реализация в текущем контексте без делегирования.

- [x] Тип Reminder и чистые функции расписания; тесты реальных дат, UTC+5, месяца и 14 дней.
- [x] Коллекция, composer и router CRUD; проверки владельца, валидации и устаревших кнопок.
- [x] Планировщик с атомарным захватом, повторной попыткой и переносом; изолированные тесты ошибок и повторных нажатий.
- [x] Тесты, типы, линтер и итоговое ревью изменённого сценария.

Проверки: полный npm test — 12 успешных тестов; после финальных исправлений целевые 11 тестов напоминаний успешны. ESLint всех затронутых файлов успешен. TypeScript успешен с `--rootDir . --noUnusedParameters false`; обычная проверка блокируется существующей конфигурацией rootDir и неиспользуемыми параметрами в categories.ts/help.ts. Ревью проведено в текущем контексте; исправлены срок захвата на длинных пачках и отображение ближайшей даты. MongoDB и Telegram подменены в тестах: проверка с реальными сервисами не выполнялась.

Границы: новые зависимости не нужны. Доставка после сбоя может повториться, если Telegram принял сообщение до падения процесса. Реальные сообщения в проверках не отправляются.
